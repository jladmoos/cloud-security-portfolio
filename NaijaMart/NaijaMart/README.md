🛒 NaijaMart – Secure Cloud E-Commerce Architecture

1. Project Overview

NaijaMart is a proposed e-commerce platform designed to handle up to 100,000 visitors during periods of high traffic.

The goal is to build a secure, scalable, reliable and cost-effective cloud infrastructure using AWS concepts.

2. Project Objectives

- Support high website traffic.
- Protect customer information.
- Secure payment processing.
- Prevent unauthorized database access.
- Minimize downtime.
- Provide backup and disaster recovery.

3. Proposed AWS Services

AWS Service| Purpose
Amazon Route 53| DNS management
Amazon CloudFront| Content delivery
Application Load Balancer| Distribute traffic
Amazon EC2| Run application servers
EC2 Auto Scaling| Adjust server capacity
Amazon RDS| Store application data
AWS IAM| Manage permissions
Amazon CloudWatch| Monitor infrastructure
AWS CloudTrail| Record account activity

4. Security Strategy

- Apply least-privilege access.
- Encrypt sensitive information.
- Restrict database access to authorized application services.
- Use security groups and network segmentation.
- Monitor suspicious activity.

5. Reliability and Recovery

- Deploy application servers across multiple Availability Zones.
- Configure database backups.
- Monitor system health.
- Develop a disaster recovery plan.

6. Project Status

Currently in the planning and architecture design phase.

7. Learning Outcomes

This project will demonstrate practical knowledge of:

- Cloud architecture
- AWS fundamentals
- Networking
- Cloud security
- Monitoring and reliability
